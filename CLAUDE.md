# Global Rules

## Communication
- Trả lời bằng tiếng Việt
- Không giải thích dài dòng, đi thẳng vào vấn đề
- Hỏi lại khi chưa hiểu vấn đề, không tự bịa ra
- Comment code bằng tiếng việt
## Code Style
- Luôn viết unit test trước khi implement
- Dùng absolute imports, không dùng relative (../../)
- Không dùng `any` trong TypeScript
- Trong vuejs luôn viết theo kiểu composition api
- Sử dụng tên biến tường minh, chuẩn quy tắc
- Frontend luôn viết dưới dạng class object
- Hạn chế tối đa sử dụng các thẻ HTML thông thường, dự án đang sử dụng naive UI
- Sử dụng icon trong folder icons nếu không có thì tạo mới
